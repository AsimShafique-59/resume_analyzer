Senior Python AI Backend Engineer

We're hiring a Senior Python AI Backend Engineer to build and scale LLM-powered
products for our platform. You'll work across backend services and applied AI,
owning features end to end from API design to production deployment.

Responsibilities:
- Design and maintain RESTful APIs using Django REST Framework and FastAPI
- Build LLM-powered applications using LangChain, LangGraph, or CrewAI, including
  RAG pipelines backed by vector databases (Pinecone, FAISS, or Chroma)
- Design and optimize PostgreSQL schemas, indexes, and queries for
  high-throughput transactional workloads
- Implement secure authentication (JWT/OAuth2) and role-based access control
- Containerize services with Docker and maintain CI/CD pipelines (GitHub Actions)
- Deploy and operate services on AWS or Google Cloud
- Collaborate with a small cross-functional team in an agile environment

Requirements:
- 2+ years building production backend systems in Python (Django or FastAPI)
- Hands-on experience with LLM frameworks (LangChain/LangGraph/CrewAI) and
  vector search / embeddings
- Strong SQL and PostgreSQL experience, including migrations and query tuning
- Experience with Docker, CI/CD, and cloud deployment (AWS/GCP)
- Comfortable owning a feature from API design through deployment
- Nice to have: React frontend experience, multi-tenant SaaS architecture
